# Whiteboard Shoot-Day Checklist

## Equipment

- [ ] 4×6 ft whiteboard, cleaned with isopropyl alcohol (no ghost marks)
- [ ] iPhone 14 Pro or better, mounted directly above whiteboard
- [ ] Tripod locked, phone parallel to surface
- [ ] Two softboxes at 45° angles to eliminate glare and shadows
- [ ] Polarizing filter on phone (optional, for reflection control)
- [ ] Reference monitor or second phone showing live frame
- [ ] Audio recorder for capturing real marker squeak SFX (separate track)
- [ ] 6 fresh Sharpies (Magnum or Mr. Sketch), each tested before use
- [ ] Red marker for Lobster Red accents
- [ ] Eraser + microfiber cloth for between-section cleaning
- [ ] Light pencil for layout guides (will erase digitally)

## Phone settings

- [ ] 4K, 60fps (will conform down to 30fps after speed adjustments)
- [ ] ProRes if available
- [ ] Manual focus locked
- [ ] Manual exposure locked
- [ ] White balance locked

## Frame

- [ ] Whiteboard fills 95% of vertical, small margin for crop
- [ ] Drawing hand: bare hand or sleeve cuff visible. No watch, no jewelry. Right-handed.

## Test footage

- [ ] No glare visible
- [ ] Sharp focus across full frame
- [ ] Marker reads black (#0A0A0A), not blue-black
- [ ] Whiteboard reads true white (#FFFFFF), not warm or cool

## Section-by-section

For each of the 8 sections:

- [ ] Practice the drawing 2–3 times before final take
- [ ] Sketch faint pencil layout guides on the whiteboard
- [ ] Roll camera + audio recorder
- [ ] Brace forearm against whiteboard edge to minimize hand shake
- [ ] Shoot multiple takes, slate each one
- [ ] Wipe whiteboard before next section, confirm no ghosting

## Wrap

- [ ] Master file labeled `whiteboard-master-4k.mov` and saved to `01-source-footage/`
- [ ] Outtakes moved to `04-archive/raw-takes/`
- [ ] Marker squeak SFX track saved separately
