# OpenClawButton Promo — Shot-by-Shot Storyboard

90-second master. Drawing speed times to the VO, not the other way around.
Practice each section 2–3 times before the final take.

Speed factors in post:
- Simple line work: 4x–6x
- Medium drawings: 6x–10x
- Complex (Python snippet, four-panel): 10x–14x
- Wipes: real time

Cut speed changes on syllable boundaries so the hand "lands" each new word.
